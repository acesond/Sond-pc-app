🔑 GitHub 토큰 Fine-grained PAT

토큰은 이 브라우저(localStorage)에만 저장됩니다. 코드에 넣지 않았고 api.github.com 외에는 보내지 않습니다.

토큰 발급 방법 (1분)
  1. Fine-grained token 만들기 열기
  2. Repository access → Only select repositories → acesond/Sond-pickle 선택
  3. Permissions → Repository permissions → Actions: Read and write (Metadata는 자동 Read)
  4. 만료일 지정 후 Generate token → github_pat_… 복사해 위에 붙여넣기

⚡ 빠른 제어 한 번 누르면 PC에서 실행

⌨️ 직접 명령 cmd
